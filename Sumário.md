# TrustLayer Documentation — Technical Writing Portfolio
Complete documentation for **TrustLayer**, a fictional company that provides identity verification (KYC) and fraud prevention APIs. This repository is a technical writing portfolio project: the company, product, API and screens are invented, and the documentation follows the standards of real-world developer and product documentation.
> [!NOTE]
> **TrustLayer is fictional.** Any resemblance to real companies or products is coincidental. All personal data in examples is invented.

## Highlights
- **REST API reference** with HTTP methods, parameters, JSON requests and responses, authentication and errors.
- **Code samples** in cURL, Node.js and Python, including token caching and webhook signature verification.
- **Diagrams** for architecture, OAuth 2.0 authentication, the verification lifecycle and webhook retries.
- **Annotated UI mockups** of the TrustLayer Console, with numbered markers that match the steps in the text.
- **Callouts** (Note, Tip, Important, Warning, Caution) using GitHub's native alert syntax.
- **Consistent example data** across both doc sets, so one case can be followed from API to Console.
